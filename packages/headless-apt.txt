# Headless package list — Debian/Ubuntu equivalent of headless.txt, installed via
# apt-get on any host with apt-get instead of pacman (VMs, Codespaces).
#
# One package per line, `#` starts a comment. Installed by install.sh with
# `apt-get install -y --no-install-recommends`, so re-runs are cheap.
#
# Not a 1:1 name mapping for everything — a few headless.txt tools have no apt
# package at all (starship, rustup, yq, lazygit, gdu, bottom, fastfetch,
# carapace, gh) and are installed separately by install.sh via official installers,
# GitHub release binaries, or a third-party apt repo. See install.sh's
# "Non-Arch (apt) package install" section for those.
